# 10K The Barber

A responsive website for 10K The Barber in Hatcliffe Ext, Harare.

## View the website

https://anotidachihwai1-cyber.github.io/10k-the-barber/

## Features

- Gold, silver and cool blue design for desktop and mobile
- Haircut services, client gallery and promotional flyer
- Booking requests through WhatsApp to +263 717 824 559
- In-shop and home-service options

Customers select a service and preferred date and time, then send the prepared request in WhatsApp. The barber confirms availability and pricing by reply.

## Editing

Edit `index.html` for content, `style.css` for appearance and `app.js` for booking behavior. Images are stored beside the page. No build step is required. GitHub Pages serves the `main` branch from the repository root.

The client gallery was cleaned using AI-assisted image editing. Branding and photos were supplied for this project.
